# 📈 TradeInsight AI

## Stock Market Analysis & Trading Signal Dashboard

TradeInsight AI is an AI-powered stock market analysis and trading signal dashboard built using Python and Streamlit.

## 🚀 Features

- 📊 Stock market data analysis
- 📈 Interactive price charts
- 📉 Historical stock data analysis
- 📊 Technical indicators
- 🤖 Trading signal generation
- 🟢 Buy signals
- 🔴 Sell signals
- 🟡 Hold signals
- ⚡ Fast and interactive dashboard

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- yFinance

## 📂 Project Structure

## ▶️ How to Run

### 1. Clone the Repository

git clone https://github.com/Ganeshbhise1904/TradeInsight-AI.git

### 2. Go to the Project Folder

cd TradeInsight-AI

### 3. Install Dependencies

pip install -r requirements.txt

### 4. Run the Application

streamlit run app.py

## 📊 Supported Analysis

The dashboard provides stock price analysis and generates trading signals based on technical indicators.
